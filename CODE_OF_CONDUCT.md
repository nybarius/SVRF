# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1, by reference.

The full text is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>, including its
translations at <https://www.contributor-covenant.org/translations>.

## Enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported by
contacting the maintainers directly through their GitHub profiles, or by opening a GitHub
issue asking for a private contact if you would rather not describe the incident
publicly. All complaints will be reviewed and investigated promptly and fairly.

(For security vulnerabilities specifically, use GitHub's private vulnerability reporting
as described in `SECURITY.md` instead.)
